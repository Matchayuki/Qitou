## 🌫️ 那块白

每个想写点什么的人，都认识它。

光标停在第一行的开头，一闪一闪，像在等你先开口。你脑子里其实有过很多句子——关于楼下那只猫、某个长得看不到头的夏天、母亲说过的一句当时没听懂的话。可它们一旦落到屏幕上就变了样：变得用力，变得工整，变得像一篇作文。

于是你关掉文档，想着等一个更好的时机再写。

多数时候，那个时机不会来。

**起头不教你写作，也不评判你写得好不好。** 它只做一件事：在你打开页面的那一刻，把第一句话递到你手里。

一句开头，或一帧画面，或一句没头没尾的对白。再附上一条限制——不许用形容词、必须写到一种气味、整段只允许一句话。

限制不是刁难。给得太少，人反而容易写得漂亮而空洞；给你一个框，你才松得下来。

然后你就写下去。三行可以，一屏也可以。写坏了没人看见。

这里没有账号，没有服务器，没有连续打卡的天数，也没有人给你的文字打分。你写下的每一个字都只留在这台设备上——没有人知道你写了什么，也没有人在数你写了多久。

起个头，就好。

## ✍️ 怎么用

**1️⃣ 打开** [matchayuki.github.io/Qitou](https://matchayuki.github.io/Qitou/)
　手机上也能用，建议「添加到主屏幕」，之后点开就像个 App。

**2️⃣ 抽一句**
　🎲 选「随便抽」——立刻给你一句；
　📅 选「今日」——从每天零点更新的三道题里挑一句，适合不想选的时候。

**3️⃣ 写下去，按「存下」**
　三行可以，一屏也可以。写完就收进「我的本子」。

> [!TIP]
> <kbd>Ctrl</kbd> + <kbd>Enter</kbd> 是存下。不满意这句，点「换一个」再抽；实在不喜欢，点「不用它」，它就不会再出现。

## 🧩 里面有什么

| | 功能 | 说明 |
|:--:|:--|:--|
| 🎲 | **三种起手式** | 开头 / 画面 / 对白。同一个意思，落在不同的地方，写出来的东西就不一样。 |
| 📅 | **今日三选一** | 每天零点更新，开头、画面、对白各一题。 |
| 🎯 | **限制** | 1 到 3 条，是给你添麻烦用的——"不许出现形容词"、"必须写到一种气味"、"整段只允许一句话"。麻烦越多，越容易写出东西来。不喜欢哪条就单独划掉那一条，只换它，其他的和正文都不动。 |
| ⏱️ | **限时** | 5 / 10 / 20 分钟。时间到了会自动帮你存下。 |
| 📓 | **我的本子** | 写过的都收在这里，可以回看、可以再编辑、可以随便翻一条。 |
| 🖼️ | **存成图片** | 把一段文字排成一页纸导出成 PNG，方便发到别处。 |
| 💾 | **完整备份** | 导出一个 JSON，换设备或换浏览器时用它恢复；也可以只导出 TXT 纯文字。 |
| 🌙 | **夜间模式** | 以及所有该有的无障碍支持：键盘操作、屏幕阅读器、减少动效。 |

## 🔒 关于隐私

这是这个项目的底线，不是功能列表里的一项。

> [!IMPORTANT]
> **你写的东西，只有你自己能看见。** 没有账号，没有服务器，没有数据库，没有统计，没有埋点。
> 所有内容只存在你自己浏览器的本地存储里（`localStorage`，键名以 `qitou.` 开头）。
> 页面一关，它还在；但**清理浏览器数据、换设备、换浏览器之前，请先导出完整备份。**

- ✅ **没有账号，不用登录**
- ✅ **没有服务器，没有数据库**
- ✅ **没有统计，没有埋点** —— 没人知道你写了什么、写了多少、什么时候写的
- ✅ **不发起任何网络请求** —— 断网、飞行模式、离线双击打开，全都照常用
- ⚠️ **唯一的例外**：你主动点「存成图片」或「导出」时，文件生成在你自己的设备上，不经过任何人的服务器

## ⚙️ 技术

**这是一个单文件应用。**

```
.
├── index.html      # 结构 + 样式 + 逻辑 + 全部素材，都在这一个文件里
├── assets/logo.svg # 田字格徽记
└── README.md
```

- 🧱 **无框架、无构建步骤、无依赖**
- 🔤 **无外部字体、无 CDN、不发起任何网络请求**
- 📂 **双击 index.html 就能用**，断网也能用
- 💾 数据存在 `localStorage`，键名以 `qitou.` 开头
- 🖋️ 字体全部走系统字体：界面中文用**等线**，题句与出处用**隶书**，正文与你自己写的字用**思源宋体**
- 🌗 日间是米黄纸面，夜间是墨色
- 🎨 单列居中 900px 的写作台：题句在上、纸在下，一进来先看见那句话
- ♿ 正文与次要文字的对比度日间夜间**全部 ≥ 4.5:1**（WCAG AA），点击区补齐到 **44px**
- 📱 窄屏下「限时」「限制条数」的面板改为从底部升起的抽屉

想改的话，下载 index.html，改完传回来就行。没有编译，没有安装。

本地预览也可以起个服务：

```bash
python -m http.server
```

## 💬 常见问题

<details>
<summary><b>我写的东西会丢吗？</b></summary>

在同一台设备的同一个浏览器里不会丢失。清理浏览器数据、换设备、换浏览器会丢——所以定期用「完整备份」导出一份。
</details>

<details>
<summary><b>能多设备同步吗？</b></summary>

暂时不能，这是"没有服务器"必须付的代价。需要搬家用「完整备份」。
</details>

<details>
<summary><b>会加分享、点赞、排行榜吗？</b></summary>

不打算。一旦有别人看，写出来的东西就变了味。
</details>

<details>
<summary><b>抽到的句子不喜欢？</b></summary>

点「换一个」换一句；点「不用它」，这句以后就不会再出现了。不喜欢某条限制，可以只划掉那一条，其他的不动。
</details>
